# Uni Pipeline

## Overview

This project demonstrates a small data engineering pipeline using academic-style student data.

The goal is to practice:

- SQL data extraction
- Data cleaning and transformation
- Python
- ETL/ELT concepts
- Data quality checks
- Git and GitHub
- Data pipeline design

## Planned Pipeline

Raw Data → Data Cleaning → Transformation → Validation → Final Dataset

## Technologies

- SQL
- Python
- Git
- GitHub
- Jupyter Notebook
